# 4krog | Cybersecurity Portfolio

I'm developing practical cybersecurity skills through web security labs, Capture The Flag (CTF) challenges, and hands-on experimentation.

My goal is to understand how vulnerabilities work, document findings, and share clear, reproducible technical writeups.

## Areas of Interest

- **Web Security:** application security and vulnerability analysis
- **CTF Challenges:** practical challenges and technical writeups
- **Ethical Hacking:** security testing in authorized environments
- **Security Labs:** hands-on experiments and Docker-based challenges
- **Security Education:** technical documentation and visual explanations

## CyberPanels

**CyberPanels** is my project for creating cybersecurity challenges, publishing technical writeups, and explaining security concepts through practical examples and visual storytelling.

The goal is to make cybersecurity learning more practical, structured, and accessible.
